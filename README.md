# SQL Server Practice
This repository contains my SQL Server practice queries and examples as I learn SQL concepts step by step.

## Topics Covered

- SQL Basics: SELECT, INSERT, UPDATE, DELETE, ALTER, MERGE
- SQL Constraints: PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, CHECK, DEFAULT
- WHERE Clause
- ORDER BY Clause
- GROUP BY Clause
- HAVING Clause
- Aggregate Functions: COUNT(), SUM(), AVG(), MIN(), MAX().

## Technologies Used

- Microsoft SQL Server
- SQL Server Management Studio (SSMS)
  
## Purpose

- Practice SQL queries with practical examples.
- Understand database concepts and SQL commands.
- Prepare for technical interviews and improve problem-solving skills.
